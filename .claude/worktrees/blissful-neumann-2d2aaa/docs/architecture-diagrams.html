┌─────────────────────────────────────────────────────────────────────────┐
│  PROCESSING PIPELINE                                                     │
│                                                                          │
│  1. REVIT AI CONVERT (revit_convert.py)                                 │
│     ├─ Input: raw_revit_export.json (1.75 MB)                          │
│     ├─ Logic: Extract hold-down families, normalize names               │
│     ├─ LLM Call: Naming pattern learning (OpenRouter)                   │
│     └─ Output: AIConvert_revit.json (72 canonical assemblies)          │
│                                                                          │
│  2. PDF PAGE INTELLIGENCE (pdf_intelligence.py + s201_detector.py)     │
│     ├─ Input: Madera PDF (S-201 Foundation Plan)                       │
│     ├─ Logic: PyMuPDF extraction, H1-H4 detection, baseline 54        │
│     ├─ BBox: (40,60,2250,1660) for plan area                           │
│     └─ Output: pdf_page_intelligence.json (54 detections)              │
│                                                                          │
│  3. PDF AI CONVERT (pdf_convert.py)                                     │
│     ├─ Input: pdf_page_intelligence.json                               │
│     ├─ Logic: Structured PDF entities with evidence                    │
│     └─ Output: AIConvert_pdf.json                                       │
│                                                                          │
│  4. RANSAC REGISTRATION (ransac_holdown.py + registration.py)         │
│     ├─ Input: Revit assemblies (72) + PDF hold-downs (54)              │
│     ├─ Logic: Mark-constrained RANSAC (H1→H1, H2→H2, etc.)            │
│     ├─ Transform: Scale 17.97 pt/ft, Rot 0.05°, Refl=true             │
│     ├─ Quality: RMS 6.22 pt, 32 inliers, confidence="high"            │
│     └─ Output: registration_calibration.json                            │
│                                                                          │
│  5. AI COMPARE (compare.py)                                             │
│     ├─ Input: AIConvert_revit.json + AIConvert_pdf.json + calibration  │
│     ├─ Logic: Location-aware matching (≤16pt = MATCH)                  │
│     ├─ Verdicts:                                                       │
│     │   • MATCH: 32 (same type, <16pt apart)                          │
│     │   • LOCATION_MISMATCH: 4 (same type, 16-40pt apart)            │
│     │   • PDF_ONLY: 18 (on PDF, no Revit partner)                    │
│     │   • REVIT_ONLY: 36 (in Revit, no PDF partner)                  │
│     └─ Output: ai_compare_report.json                                   │
│                                                                          │
│  6. REVIEW OVERLAY (review_overlay.py)                                   │
│     ├─ Input: ai_compare_report.json                                   │
│     ├─ Logic: Render page PNG, build SVG boxes/connectors             │
│     │   • 🔴 Red: LOCATION_MISMATCH (box + connector line)            │
│     │   • 🔵 Blue: PDF_ONLY (box)                                      │
│     │   • 🟠 Orange: REVIT_ONLY (on-sheet only)                       │
│     │   • 🟢 Green: MATCH (hidden by default)                         │
│     └─ Outputs:                                                        │
│         • s201_review_page.png (2592×1728 @ 150dpi)                   │
│         • s201_review_overlay.svg (vector boxes)                       │
│         • s201_review_overlay.png (burned-in annotations)              │
│         • s201_review_items.json (90 items, 90 drawable, 0 undrawable)│
